# 兼容矩阵

本页只描述组件角色，不提供真实补丁目标、完整依赖图或发行数据。

| 组件类别 | 在组合中的角色 | 组合冲突 | 架构侧处理 |
|---|---|---|---|
| Harmony | 运行时方法补丁基础 | 补丁顺序、签名变化 | 窄目标 Postfix、能力探测、失败降级 |
| Humanoid Alien Races | 种族与 BodyAddon 渲染基础 | 节点结构和 Graphic 创建路径变化 | 在最终 Graphic 边界兜底，避免接管纹理选择 |

## 加载关系原则

- 兼容补丁应在被兼容的目标 Mod 之后加载；
- 硬依赖只列缺失时无法工作的组件；
- 单纯的顺序要求使用 `loadAfter`，不要伪装成硬依赖；
- 已被整合的参考 Mod 与本 Mod 同时启用时会重复修改相同节点，应在发行说明中提示；
- 可选扩展必须按其直接 packageId 门控。

## 版本漂移应对

上游升级后优先验证：

1. 类型和方法签名是否改变；
2. BodyAddon 的路径与条件结构是否改变；
3. 基因 Def 是否被删除或重命名；
4. 渲染缓存刷新入口是否仍然有效；
5. 静态补丁是否出现死 XPath；
6. 与其他运行时补丁的先后顺序是否改变。
